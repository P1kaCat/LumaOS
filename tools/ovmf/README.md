# OVMF Firmware

Placez ici les fichiers OVMF pour QEMU :

- `OVMF_CODE.fd` — firmware UEFI (lecture seule)
- `OVMF_VARS.fd` — template des variables NVRAM (jamais modifié directement)

## Téléchargement

https://qemu.weilnetz.de/test/ovmf/usr/share/OVMF/

Téléchargez `OVMF_CODE.fd` et `OVMF_VARS.fd` et placez-les dans ce dossier.
