# Contribuer à LumaOS

## Philosophie de développement : IA-first

Pendant la phase expérimentale, LumaOS est développé exclusivement avec l'aide de l'IA. Aucun développeur humain n'est prévu au début.

L'IA est utilisée pour :
- Écrire du code
- Générer des prototypes
- Expliquer du code
- Concevoir des architectures
- Debugger
- Générer des tests
- Documenter
- Rechercher des solutions
- Optimiser
- Automatiser le développement

Le créateur se concentre sur :
- La vision et la direction du projet
- La direction artistique et l'UX/UI
- Le game design de l'expérience système
- Les choix fonctionnels
- Les tests et la validation
- La roadmap

## Passage à un projet sérieux

Si LumaOS devient un projet sérieux (communauté, financement, entreprise, partenariats), des développeurs humains spécialisés pourront être intégrés uniquement lorsque l'IA ne suffit plus.

Domaines potentiellement concernés : kernel, drivers GPU, sécurité, systèmes bas niveau, performances, compatibilité matérielle, reverse engineering, validation, infrastructure.

## Principe fondamental

**Ne pas essayer de recréer Windows.**

Chaque composant doit répondre à une question :

> Est-ce nécessaire pour faire fonctionner et améliorer l'expérience gaming ?

Si la réponse est non, le composant peut être supprimé, simplifié ou repoussé.
